# Product Scope

## Purpose

This application is an interim student wellbeing and casework platform for school teams including SENDCO, pastoral, behaviour, and safeguarding. It is not a full MIS.

## Core Outcomes

- Search and open a student quickly
- Understand wellbeing state from one profile view
- See active radar relationships across teams
- Log concerns, meetings, actions, and chronology events
- Manage permissions, roles, teams, and cross-team visibility inside the app
- Support secure filtered working views and saved views

## In Scope

- Dashboard
- Student directory
- Student profile
- Concerns and triage
- Meetings and interactions
- Team radar management
- Actions and chronology
- Reports-ready filtered exports
- Settings for users, roles, permissions, teams, visibility rules, and sign-in policy
- Audit logging and saved filters

## Out of Scope

- Full attendance, behaviour, assessment, admissions, or parent portal MIS features
- Native mobile apps
- Direct external agency integrations in this release
- Fully automated Google token verification beyond Apps Script hosted session context
